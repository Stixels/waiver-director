# Security Policy

## Reporting A Vulnerability

Please do not report suspected vulnerabilities in public GitHub issues, pull requests, discussions, or comments.

Use the **Report a vulnerability** form in the repository's **Security** tab. It creates a confidential report
visible to repository maintainers instead of a public issue. Include enough detail to reproduce and assess the
issue, but do not include credentials, access tokens, customer data, or other sensitive information in the
initial report.

## Handling Sensitive Information

If you believe a credential or other secret has been exposed, treat it as compromised and notify a maintainer
privately. Do not repost the value or open a public remediation pull request that includes it.
