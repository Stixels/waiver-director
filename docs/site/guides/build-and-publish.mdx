---

Each workspace has one waiver. Open **Waiver** in the sidebar to edit it.

## Edit the draft

The waiver builder has three parts:

- **Title**: shown at the top of the public waiver page. Rename it from the page header.
- **Waiver copy**: the terms signers agree to, written in a rich-text editor with headings, lists, links, and alignment.
- **Custom fields**: questions signers answer before signing.

Every waiver also collects the signer's details and a drawn signature, and lets an adult add **covered minors** who are signing under the same waiver.

You can also choose a light or dark theme for the public waiver page.

### Custom field types

| Type     | Use it for                                                   |
| -------- | ------------------------------------------------------------ |
| Text     | Free-form answers, such as an emergency contact              |
| Checkbox | Agreements or yes/no questions                               |
| Dropdown | One choice from a list, such as "How did you hear about us?" |
| Date     | Dates, such as a date of a previous visit                    |

Any field can be marked required. Dropdown answers feed into [analytics](/guides/analytics).

## Publish

Publishing saves the current draft as a new **published waiver version** and makes it the version customers sign. Edits you make after publishing stay in the draft until you publish again.

<Warning>
	Publishing requires a Pro plan or trial. On the Free plan you can build the waiver and preview the
	public signing page, but customers cannot submit it.
</Warning>

## Version history

Open the version history from the waiver page to see every version you have published. Signed submissions always point to the exact version the signer accepted, so older signatures keep their original wording after you republish.
