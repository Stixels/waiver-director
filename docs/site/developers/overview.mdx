Waiver Director is a SvelteKit app backed by Convex. The source lives in [Stixels/waiver-director](https://github.com/Stixels/waiver-director).

## Tech stack

- [SvelteKit](https://svelte.dev/docs/kit) and Svelte 5 (runes mode)
- [Convex](https://convex.dev) for the database, backend functions, scheduled work, and HTTP endpoints
- [Clerk](https://clerk.com) for identity and billing
- [Resend](https://resend.com) for transactional email
- Tailwind CSS, shadcn-svelte, Bits UI, and Lucide icons
- pnpm for package management, deployed on Vercel

## Repository layout

```text
src/routes/(app)/app/     Protected workspace app
src/routes/(auth)/        Sign in, sign up, and auth callbacks
src/routes/(marketing)/   Public marketing, pricing, privacy, and terms pages
src/routes/w/[slug]/      Public waiver signing flow (and /b/[token] booking links)
src/convex/               Convex schema, queries, mutations, actions, crons, and HTTP routes
src/lib/                  Shared components, domain logic, config, and utilities
docs/agents/              Engineering guidance for contributors and coding agents
docs/adr/                 Architecture decision records
docs/site/                This documentation site (Mintlify)
```
