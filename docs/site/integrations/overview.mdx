Open **Integrations** in the sidebar to connect a provider. Only Owners can connect or disconnect integrations.

| Provider         | Type            | Status      |
| ---------------- | --------------- | ----------- |
| Bookeo           | Booking         | Available   |
| Mailchimp        | Email marketing | Available   |
| Xola             | Booking         | Coming soon |
| Constant Contact | Email marketing | Coming soon |
