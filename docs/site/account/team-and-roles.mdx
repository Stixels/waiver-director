---
title: 'Team and roles'
description: 'What Owners and Staff can do in a workspace.'
---

Every workspace member has one of two roles. Permissions are enforced on the server for every action, not just hidden in the interface.

| Action                                                 | Owner | Staff |
| ------------------------------------------------------ | :---: | :---: |
| Review bookings, submissions, customers, and analytics |   ✓   |   ✓   |
| Edit and publish the waiver                            |   ✓   |   ✓   |
| Write follow-up emails and manage the follow-up queue  |   ✓   |   ✓   |
| Connect or disconnect Bookeo and Mailchimp             |   ✓   |       |
| Change the workspace name or logo                      |   ✓   |       |
| Delete the workspace                                   |   ✓   |       |

<Info>
	Over time, more high-impact configuration (such as the waiver, follow-up content, and sender
	identity) is planned to become Owner-only, so Staff focus on day-to-day operations. This page is
	updated as those permissions change.
</Info>

The person who creates a workspace is its first Owner.

<Note>Team access, which lets you add Staff to a workspace, requires a Pro plan or trial.</Note>
