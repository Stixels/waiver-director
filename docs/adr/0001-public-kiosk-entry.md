# Public kiosk entry

Waiver Director will support a public workspace-scoped kiosk entry so customers can find upcoming booking-linked waivers or start unlinked signing without requiring an operator login on the device. This keeps front-desk and QR workflows simple, but the public entry must be constrained to minimal booking lookup for recently started and near-term upcoming bookings, booking-level signing without participant roster exposure, public signing only, rate limiting, no customer history exposure, and automatic reset after inactivity or submission.
