# Convex Backend

This directory contains Waiver Director's Convex schema, functions, scheduled work, and HTTP routes.

Before changing backend code, read the repository guidance in
[`docs/agents/convex-backend.md`](../../docs/agents/convex-backend.md) and the
generated Convex rules in [`_generated/ai/guidelines.md`](_generated/ai/guidelines.md).

Keep workspace authorization and signed-record integrity in trusted backend code. Hosted-service
configuration, credentials, and deployment procedures are intentionally outside this public repository.
